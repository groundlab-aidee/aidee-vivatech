# STEP 3 질문 프롬프트 차이

## 빠진 내용

- 현재 구조에서는 기준 시점에 없던 항목이 빠진 것이 아니라, 현재 하위 주제 외의 다른 주제 내용은 계속 전달되지 않는다.

## 추가된 내용

- 3-3 구간 소개
- 현재 하위 주제의 `참고`
- 앞 구간에서 확정된 Problem Statements
- 핵심 질문을 제품명만 붙여 만들지 말고 문장 구조부터 새로 만들라는 지시
- 심화 질문 방향을 순서대로 읽거나 나열하지 말라는 지시
- 프로젝트 제품 유형·사용 장면·앞선 대화를 반영하라는 지시
- 진행·구조 표현 금지 규칙

## 바뀐 지시

- 기준 시점은 현재 하위 주제의 핵심 질문을 한 번에 하나 만들도록 짧게 지정했다.
- 현재는 핵심 질문의 의도를 쉬운 표현으로 재구성하고 프로젝트 맥락을 반영하도록 같은 요구가 scoped prompt와 `[STEP 3 진행 지시]`에 함께 들어간다.

이 비교 이후에는 질문 생성 지시 자체를 추가로 변경하지 않고, 사용자 답변 판정·저장 분리·질문 절단 안전장치만 수정한다.
