# STEP 3 Relationship 첫 핵심 질문 프롬프트 기준 시점 재구성

기준: Relationship 실패·회복 결과 제거 문제가 확인된 테스트 당시의 질문 생성 구조.

## Aidee에게 전달된 순서

1. `getExpertPrompt('aidee')`
2. 공통 규칙
   - 한국어로 답한다.
   - 내부 단계 key, 시스템 UI 마커, 버튼 동작을 사용자에게 설명하지 않는다.
   - 현재 지정된 하위 주제의 질문 하나만 출력한다.
3. prompt.ts에서 동적으로 추출한 `[STEP 3 대화 운영 규칙]`
4. 현재 하위 주제 `userProduct`
5. 현재 하위 주제의 `확인할 내용`
6. 현재 하위 주제의 `심화 질문 방향`
7. 현재 단계 `step_3_persona`
8. 프로젝트명·requirements·레퍼런스 분석·레퍼런스 가이드라인
9. 마지막 `[STEP 3 진행 지시]`

## 기준 시점의 핵심 질문 지시

현재 하위 주제는 `사용자와 제품의 관계`이고 질문 종류는 `핵심`입니다. 이 하위 주제에 대한 핵심 질문을 한 번에 하나만 합니다. 다른 하위 주제로 넘어가거나 결과 블록을 작성하지 않습니다. 결과 마커도 출력하지 않습니다.

## 기준 시점의 특징

- 전체 STEP 3 주제 목록은 scoped prompt에 전달하지 않는다.
- 현재 하위 주제의 확인할 내용과 심화 질문 방향은 prompt.ts에서 동적으로 가져온다.
- 결과 형식은 대화 구간 prompt에 포함하지 않는다.
- 결과 출력 여부와 순서는 서버의 `[STEP 3 진행 지시]`가 관리한다.
