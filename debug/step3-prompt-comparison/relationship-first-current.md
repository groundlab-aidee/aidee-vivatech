# STEP 3 Relationship 첫 핵심 질문 프롬프트 현재 재구성

## Aidee에게 전달되는 순서

1. `getExpertPrompt('aidee')`
2. 공통 규칙
   - 한국어로 답한다.
   - 내부 단계 key, 시스템 UI 마커, 버튼 동작을 사용자에게 설명하지 않는다.
   - 현재 지정된 하위 주제의 질문 하나만 출력한다.
3. prompt.ts에서 동적으로 추출한 `[STEP 3 대화 운영 규칙]`
4. 현재 구간 소개: `3-3. Keywords: Relationship`의 첫 설명
5. 현재 하위 주제 `userProduct`
6. 핵심 질문 작성 규칙
   - 확인할 내용이 드러나는 쉬운 질문을 새로 만든다.
   - 제품명만 덧붙이지 않는다.
7. 현재 하위 주제의 prompt.ts `확인할 내용`
8. 현재 하위 주제의 prompt.ts `심화 질문 방향`
9. 현재 하위 주제의 prompt.ts `참고`
10. 심화 방향을 순서대로 읽거나 나열하지 말라는 추가 규칙
11. 현재 단계 `step_3_persona`
12. 프로젝트명·requirements·앞선 확정 결과(Problem Statements, Relationship 구간에서는 Keywords: Experience 포함)
13. 레퍼런스 분석·레퍼런스 가이드라인
14. 마지막 `[STEP 3 진행 지시]`

## 현재 핵심 질문 지시

현재 응답의 하위 주제는 `사용자와 제품의 관계`이고 질문 종류는 `핵심`입니다. 프로젝트의 제품 유형·사용 장면·앞선 대화를 반영해 핵심 의도를 쉬운 표현으로 새로 묻는 질문 하나만 합니다. prompt.ts의 질문 문장을 그대로 복사하거나 제품명만 덧붙이지 않습니다. 다른 하위 주제로 넘어가거나 결과 블록을 작성하지 않습니다. 결과 마커도 출력하지 않습니다.

## 현재 추가 제약

- 현재 구간 소개와 현재 하위 주제의 `참고`가 추가되었다.
- 앞 구간의 확정 결과가 추가되었다.
- 핵심 질문을 프로젝트 맥락에 맞게 새로 만들라는 지시가 `[STEP 3 진행 지시]`에도 반복된다.
- 진행 표현 금지 규칙이 마지막 지시에 추가된다.
- 재지시 차례에는 직전 질문 원문을 함께 전달하고 같은 문장 반복을 금지한다.
